# dsh-sidebar-mica-acrylic

✨ **Windows 11 云母 (Mica) 与亚克力 (Acrylic) 侧栏材质效果插件**，专为 DeepSeek Harness (DSH) 打造。

专注为 DSH 左侧栏注入现代通透、高质感的视觉体验，支持深色/浅色主题自适应流转、参数微调与内置设置页实时配置，右侧主对话区与顶栏保持原生默认。

---

## 🎨 材质模式 (Material Modes)

| 材质模式 | 说明 | 视觉特点 |
| :--- | :--- | :--- |
| **原生默认 (None)** | 还原 DSH 官方经典单色侧栏 | 纯色底衬，无额外渐变或模糊层 |
| **Windows 11 云母 (Mica)** | 微软 Windows 11 标志性材质 | 柔和珍珠微光与背景环境光影流转，清透典雅、低功耗 |
| **Windows 11 亚克力 (Acrylic)** | Fluent Design 经典磨砂毛玻璃 | 层次分明的半透明毛玻璃质感，高饱和度透光与细腻边框高光 |
| **增强云母 (Mica Alt)** | 强化反差与深层光影的增强版云母 | 饱满的环境光晕，专为沉浸式主导航与标签页定制 |

---

## 🌟 核心特性 (Key Features)

- **原生级半透明质感**：基于 Windows 11 原生材质架构与纯透明 Alpha 通道设计，侧栏轻盈通透。
- **DeepSeek 品牌蓝标识**：侧栏顶部的经典小鲸鱼图形与文字标识（Brand Wordmark）统一渲染为官方品牌蓝（`#4D6BFE`），搭配反白高对比 HARNESS 徽章与悬停弥散光晕。
- **通顶一体化视觉**：可选将侧栏向上平滑贯穿延伸至窗口顶端，消除顶栏割裂感，主会话区保持原生不变。
- **精细化参数微调**：内置侧栏不透明度（40% ~ 100%）与高斯模糊半径（0px ~ 64px）无级滑块调节。
- **Fluent 微噪点质感**：基于 GPU 硬件加速的 SVG 细腻噪点，彻底消除大面积半透明渐变的色阶断层。
- **原生深浅色自适应**：无缝跟随系统与 DSH 的浅色 / 深色主题，光影自动流转切换。

## ⚙️ 插件设置 (In-App Settings)

插件完全集成至 DSH 内置设置面板中，开箱即用，无需手动修改任何配置文件：

1. **「通用设置」快捷选择行 (General Settings Item)**:
   - 位于设置面板的「通用」标签页内。
   - 提供直观的卡片化单选方块（原生默认 / 云母 / 亚克力 / 增强云母），随点随换，即时生效。
2. **「侧栏材质」专属设置面板 (Dedicated Settings Section)**:
   - 位于设置面板左侧导航栏的「侧栏材质」标签页。
   - **实时效果预览 (Live Preview)**：交互式微型模拟侧栏，直观呈现当前材质在深浅模式下的光影与可读性。
   - **材质模式选择**：切换原生、云母、亚克力与增强云母。
   - **侧栏底色不透明度调节 (Opacity)**：40% ~ 100% 自由滑块微调。
   - **磨砂模糊半径调节 (Blur Radius)**：0px ~ 64px 高斯模糊深度调节。
   - **左侧栏通顶延伸开关 (Extend to Top)**：在 Windows 桌面端将侧栏向上平滑贯穿至顶端。
   - **DeepSeek 图标与文字品牌蓝开关**：自由开启或还原默认单色品牌标识。
   - **Fluent 细腻微质感噪点 (Micro-Noise Grain)**：细腻微噪点开关。
   - **一键恢复推荐默认值**：快速重置为官方最佳调校参数。

## 📦 安装与使用 (Installation)

### 方式一：本地插件加载
1. 将本项目文件夹放置于您的 DSH 插件目录（例如 `C:\Users\<用户名>\Documents\DSH\左边侧栏云母亚克力效果`）。
2. 在 DSH 配置文件（`cordis.patch.yml`）中添加引用，或通过 DSH 插件管理器加载。
3. 重新加载或按 `Ctrl + R` 刷新 DSH 界面即可。

### 方式二：Git 克隆
```bash
git clone https://github.com/hfbcwhy7gh-cpu/dsh-sidebar-mica-acrylic.git
```
